โดเมนขอเป็น https://forge.sornkan.com/ ด้วยนะ demo อ่ะ
ฉันว่าสไต์เดิมก็ดูเรียบหรูอยุ่แล้วแฮะ เอาเป็นตัวอย่าง theme ให้เลือกตอนจะสร้างใหม่มะ
ตอนกด open project มาอ่ะ มันต้องเป็นของผู้ใช้คนนั้นปะ ไม่ใช่ว่าทุกคนได้ project เดียวกันหมดนะ
ลูกค้าไม่เห็นสไตล์ default อ่ะ สิ จริง ๆ น่าจะมีให้พิมพ์ได้ปะ ว่าจะเอาสไตล์ไหน หรือทำระบบอะไร หรือ web MCP มันมาอ่านทีหลังได้ปะ ?
แบบถ้าเป็น custom ต้องเชื่อม web mcp นะ อะไรงี้
เลือก style ต้องมีตัวอย่างให้ดูด้วยสิด้านขวาก็ได้มะ
ตัวอย่างอยากให้เป็น style ชัดเจนกว่านี้แฮะ … https://v3.tailwindcss.com/ เหมือนตัวเลือกแบบนี้อ่ะ เเล้วเขาเห็น สไตล์เปลี่ยนไป simple playful elegant brtalist อะไรงี้ เราเอาตามนี้เลยก็ได้นะ แต่ตัวอย่าง card อาจเปลี่ยนไปตามรูปแบบของตัวระบบที่เขาเลือกเช่น ecom แสดงแบบนี้ (หาภาพประกอบฟรีมาหมุนด้วยนะ) เว็บอื่น ๆ แสดงตามตัวอย่างที่ควรจะเป็น
css ไม่ต้องแสดงนะ เน้นแสดง visual ที่เขาจะเห็นมากกว่า ถ้าเป็น ส่วนอื่น อยากให้แสดงมากกว่า ecom อ่ะ เหมือนมี ecommerc 2 ตัวอย่างเลย คิดหน่อยระบบอะไรที่เขาน่าจะมาใช้เราได้อีก lms, จองห้อง ? หรืออะไรดี ให้มันว้าว ๆ หน่อย
แต่ละตัวอย่าง มีมิติมากขึ้นมากกว่าแค่ card เฉย ๆ นะ เราขยายภาพออกมาได้อีกให้เห็นชัดขึ้นว่าสไตล์แตกต่างโดดเด่น สวยงามขนาดไหนในเว็บไซต์ และสามารถขยายขอบเขตให้เห็นชัดขึ้นได้อีกเช่น cafe ให้รู้สึกได้ถึง การจัดการออเดอร์หลังบ้านก็ได้ room นี่น่าจะมี สไตล์ที่มากขึ้น ฉันรู้สก 2 บรรทัดแบบนี้มันทื่อ ๆ ไป หรืออื่น ๆ อีกอย่างที่อยากได้คือ อยากให้ใช้ภาพประกอบมากขึ้น โดยเป็นภาพที่ เห็นหน้าคน ตามสไตล์เช่น playful เป็น เด็กผู้หญิง อื่น ๆ ก็เป็นคนตามสไตล์นั้น ขอแบบที่ free นะเอามาใช้อ่ะ
ส่วนของ ui คิดว่า ถ้าเลือก blank มันควรเป็น custom theme และมีให้ใส่ prompt ไหมอ่ะ เพื่อส่งต่อไปให้ WebMCP สร้างอีกทีตอนเขาเข้าร่วม studio มาแล้ว อะไรงี้ custom style ก็ด้วย คือมันเป็น custom สองอันคือ พิมพ์สิ่งทีอยากสร้างเอง แบบ What you want to build กับ สไตล์ที่ต้องการ rework ui หน่อยมันควรเป้นแบบไหนที่ให้รองรับทั้ง prefill และ custom และแสดงตัวอย่างได้อย่างกลมกลื่นสวยงาม
มันซ้ำเกินไป ไปดู ตัวอย่างแบบเดิมอ่ะ มันต้องเป็นแบบนั้น เปลี่ยนไปเลย ไม่ใช่ภาพเหมือนกันทุก system แบบนี้ ภาพประกอบที่บอกคือ อย่าง store อ่ะ ตอนนี้เห็นแค่เสื้อ มันควรเป้นแบบที่มีคนด้วย playful เป็น เด็กอะไรเงี้ย ดูที่หน้าแรกของ plan มันคือสไตล์นั้นแต่ขยายออกมา และสร้างความแตกต่างของฟีเจอร์ในระบบแต่ละแบบ
ตัว simple ก็ยังไม่เห็นคนนะ room ก็ต้องไม่เห็นคนอ่ะ เด็กขอภาพมองตรง โตกว่านี้หน่อยสักประถม แล้วก็ ui จองห้องประชุมให้มันว้าวกว่านี้หน่อย อันนี้ดูเรียบ ๆ อ่ะ
cafe, learn, store ขอดูดีกว่านี้ บางจุดยังแปลก ๆ เช่น ชิดขอบ หรือใส่ค่าสีไป มันควรแสดงฟีเจอร์ของ cafe ไม่ใช่ style guide line [แนบภาพหน้าจอ cafe และ learn]
ใน system อื่น ๆ ก็ควรเปลี่ยนสไตล์ภาพที่ใช้ด้วยครับ ให้เข้ากับ สไตล์ที่เลือก ห้องเรียน หรือ course หรืองานจองห้องก็ควรเปลี่ยนภาพด้วย
